
# E-TRUCK: ECHO MATRIX + UGSR

## Project Overview

This project investigates geometry-aware communication
degradation detection and recovery for connected truck
platooning in GPS-denied and high-interference environments.

## Core Components

### ECHO MATRIX
A proposed sensing layer for estimating relative vehicle
geometry using UWB measurements.

### UGSR
A proposed decision and recovery layer that uses
communication degradation and spatial information to
classify interference patterns and select recovery actions.

## Current Stage

Phase 0 / Initial simulation setup.

The project is currently establishing its software
environment and simulation foundations. The proposed
mechanisms have not yet been experimentally validated.

## Initial Objectives

- Simulate a group of vehicles moving along a road.
- Represent communication links between vehicles.
- Model localized communication degradation.
- Visualize affected links and vehicle positions.
- Record reproducible experiment results.

Simulation results must be distinguished from assumptions
and hypotheses. Safety and performance claims require
appropriate testing and evidence.
